Quality note:

Important:
- Use custom icons for Campus Connect-specific modules.
- Use universal/provider icons only where they represent the actual external provider
  or universally understood action.
- For functional UI icons that already have a reliable icon-library equivalent
  (e.g. close, chevron, search), prefer the coded SVG/icon-library version when
  accessibility and scalability are more important than the decorative illustration.
