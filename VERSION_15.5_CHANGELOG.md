# CampusConnect Version 15.5

Requested-only UI update.

- Removed the extra function/action buttons from the Dashboard Announcements panel.
- Added an optional student-uploaded club image to the Create Club flow; uploaded images are stored in the existing `clubs.logo` field and displayed on club cards, with the existing campus image remaining the fallback.
- Refreshed the existing My Profile card styling without changing the profile grid/card dimensions.
